# Ollama

Каталог предназначен только для конфигурации контейнера Ollama и его
последующего развёртывания через Komodo.

В репозиторий должны попадать только `docker-compose.yml`, безопасный шаблон
`.env.example`, этот README и `.gitignore`. Модели, данные, кэши, секреты,
исходный код, документация и файлы IDE должны оставаться локальными.

Новый файл конфигурации разрешается в `.gitignore` только явно.
